# openclaw-skills
A curated collection of OpenClaw skills following Anthropic's best practices, designed to enhance daily productivity, work efficiency, and learning workflows through well-structured prompt engineering.

## Skills

- `daily-journal` - Capture and structure daily journal entries.
- `journal-reviewer` - Review journal archives and surface patterns.
- `skill-creator` - Create new OpenClaw-compatible skills.
- `knowledge-glossary` - Turn messy project language into a reusable concept map for teams and AI agents.
